    \section{Updates for April 15, 2025}
    The following updates will be pushed to OSU Drupal Development Tuesday, April 15\textsuperscript{th} 2025.
    Barring any issues, we will deploy this update to Production on Thursday, April 17\textsuperscript{th} 2025.

    \subsection{What's New}\label{subsec:what's-new}

    \subsubsection{Site wide Alerts.}
    A new role is added to create and manage alerts on sites.
    Alerts can be Published/Unpublished on a schedule and limited to pages

    \subsubsection{Responsive Table filter}
    All HTML Tables created in CKEditor will be wrapper in a responsive div.
    This will enhance the usability of tables on mobile/tablet devices.

    \subsubsection{Fontawesome Version}
    Fontawesome has been updated to 6.7.2 and brings many updates to icons.

    \subsubsection{Drupal Link Purpose}
    The library adds a span to prevent a line break between the last word of the link and the icon.
    This can cause a horizontal scrollbar to appear if the last word of the link is longer than the page -- e.g., someone linking a very, very long URL, which is BAD, but we want the broken site to be their fault, not ours.

    The library now checks and does not add the noBreak span if the last word in the link is longer than 30 characters (``antidisestablishmentarianism'' is 28).
